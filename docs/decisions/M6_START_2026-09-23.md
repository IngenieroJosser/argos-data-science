# M6 Start Decision — 2026-09-23

## Decision

**M6 — Productionization & MLOps: ▶ IN PROGRESS.**

M5 is formally closed and its negative evidence travels unchanged into M6. ARGOS V1 is operationalized as a batch-first, shadow/human-review system. The milestone does not reopen model selection and does not pre-authorize production promotion.

## Senior design choices

1. **Batch before online serving.** The decision process is review-queue prioritization, so a low-latency API has no demonstrated requirement.
2. **Immutable lineage.** Model, calibrator, feature registry, cards and monitoring contract are registered by SHA-256.
3. **Idempotent scoring.** A batch id is derived from immutable input + model + calibrator + scoring contract.
4. **Executable monitoring.** M5 thresholds become code and alerts have explicit operational actions.
5. **Human-in-the-loop.** Model evidence and human outcomes are separate data fields/artifacts.
6. **Reversible operation.** Shadow/pause/rollback transitions are explicit and tested.
7. **No production auto-promotion.** Current drift/degradation evidence is not bypassed by engineering readiness.
8. **Auditability.** Operational events are persisted in a hash-chained append-only log.

## Non-goals

M6 does not create a corruption/fraud classifier, causal conclusion, autonomous sanctioning system, online API without need, or a new model selected using consumed holdouts.

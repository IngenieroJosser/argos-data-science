## Model families V1

- prevalence + historical heuristic;
- linear logistic model mediante SGD streaming;
- histogram gradient boosting con muestra TRAIN determinística;
- calibration: none / sigmoid / isotonic.

La elección de `HistGradientBoostingClassifier` evita introducir una dependencia externa de boosting en M4 V1 y mantiene reproducibilidad local. CatBoost/LightGBM/XGBoost pueden evaluarse posteriormente como experimentos versionados si existe evidencia de valor incremental.

## Acceptance floor

Antes de TEST se congelan los mínimos:

- validation-selection PR-AUC > prevalence;
- validation-selection Lift@1% > 1;
- final TEST Lift@1% > 1.

El objetivo es demostrar capacidad de priorización por encima de revisión aleatoria, no optimizar contra TEST.

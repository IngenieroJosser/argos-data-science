# Decision — Inicio de M3 Gold

> **Nota de trazabilidad:** este documento registra la decisión de inicio de M3. El estado vigente está supersedido por `M3_GATE.md`: M3 ✅ CLOSED.

**Fecha:** 2026-09-23  
**Estado:** ACCEPTED

## Contexto

M2 cerró con su gate formal y dejó una capa Silver canónica, tipada, trazable y con incertidumbre de entity resolution explícita. Gold puede comenzar sin volver a interpretar Bronze.

## Decisión

M3 adopta `m3-gold-v1` y construirá el primer dataset de modelado con:

- unidad analítica: un contrato evaluado en `t0`;
- `t0 = fecha_de_firma`;
- target V1: `y_addition_180d`;
- evento positivo: `ADICION EN EL VALOR`;
- ventana: `(t0, t0 + 180 días]`;
- censura explícita;
- validación temporal, no aleatoria;
- features contractuales conservadoras;
- históricos estrictamente `< t0`;
- competencia con `publication_at <= t0`;
- gate final M3 antes de Modeling.

## Restricciones

Silver no autoriza automáticamente ninguna columna como feature. `contracts_snapshot_state.parquet` permanece fuera del model matrix V1. Los valores monetarios del snapshot contractual actual no se habilitan como features V1 hasta demostrar su semántica point-in-time.

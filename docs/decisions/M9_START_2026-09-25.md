# Decisión — inicio de M9 Plataforma Analítica

**Fecha:** 2026-09-25  
**Estado:** `APPROVED TO START`

## Contexto

ARGOS completó su implementación científica/técnica. M1–M6 están cerrados; M8 cerró como `RESEARCH_COMPLETE_NO_PROMOTION`; M7 permanece activo porque necesita evidencia prospectiva futura.

## Decisión

Se inicia **M9 — Plataforma Analítica / Frontend** como una línea de producto independiente.

M9 puede avanzar mientras M7 continúa activo porque el frontend no modifica el protocolo prospectivo, el modelo V1 congelado ni los artefactos de evaluación consumidos.

## Alcance aprobado

- Next.js + TypeScript;
- design system y UX analítica;
- Overview;
- ranking/prioridad de revisión;
- Contract Intelligence;
- Supplier / Entity Intelligence;
- Graph Explorer;
- Anomaly Explorer;
- Survival / temporal intelligence;
- Monitoring;
- Methodology & Governance;
- contrato de datos de presentación versionado;
- testing de frontend y flujos críticos.

## Restricciones

M9 no autoriza:

- cerrar M7 sin evidencia prospectiva madura;
- cambiar el target V1;
- reabrir TEST 2025 u OOT 2026 para selección;
- promover automáticamente features M8;
- ejecutar entrenamiento/tuning desde el frontend;
- presentar scores como conclusiones de fraude/corrupción;
- decisiones jurídicas autónomas.

## Fuente de verdad

La capa científica/MLOps existente permanece como fuente de verdad. M9 consume una proyección de presentación derivada de artefactos gobernados.

## Próximo entregable

Implementar M9.1: estructura de aplicación, design system, layout, navegación, estados de UI y contrato inicial `m9-presentation-v1`.

Plan completo: `docs/M9_FRONTEND_PLAN.md`.
